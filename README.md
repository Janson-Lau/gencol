# gencol

**gencol** is a lightweight CLI tool for Go, auto\-generating **GORM column constant structs** from your model code\.

It eliminates hard\-coded column strings in SQL queries, avoids spelling errors, ensures compile\-time safety, and supports both **interactive mode** and **go generate** mode\.

## Features

- Auto parse standard `gorm:"column:xxx"` tags

- **Do not generate table name** \(fully compatible with custom `TableName()` logic\)

- Interactive CLI with default path prompt, one\-click generation

- Silent mode for `go generate` automated execution

- Compile\-time column name verification, no manual string hardcoding

- Zero intrusion on original business model code

## Install

Require Go 1\.18\+

```bash
go install github.com/Janson-Lau/gencol@latest
```

## Usage

### 1\. Interactive Mode \(Recommend\)

Run directly without parameters, press Enter to use the default path:

```bash
gencol
```

Default Paths:

- Model source directory:`./internal/models`

- Generated file output directory: `./internal/meta`

### 2\. Silent Mode \(For go generate\)

Suitable for project automated build integration:

```bash
gencol ./internal/models ./internal/meta
```

### 3\. Check Tool Version

```bash
gencol -v
```

## Real Business Example \(User Model\)

### Original Model Code `user.go`

Standard GORM business model with custom `TableName()`:

```go
package models

import (
	"time"	
	"gorm.io/gorm"
)

type User struct {
	Id        int64  `gorm:"column:id;type:bigint;primary_key"`
	Username  string `gorm:"column:username;type:varchar(100);not null"`
	Password  string `gorm:"column:password;type:varchar(100);not null"`
	Phone     string `gorm:"column:phone;type:varchar(100);not null"`
	Email     string `gorm:"column:email;type:varchar(100);not null"`
	IsActive  bool   `gorm:"column:is_active;type:tinyint;not null;default:1"`
	CreatedAt int64  `gorm:"column:created_at;type:bigint;not null;autoCreateTime:milli"`
	UpdatedAt int64  `gorm:"column:updated_at;type:bigint;not null;autoUpdateTime:milli"`
}

func (t *User) TableName() string {
	return "user"
}
```

### Generated Code `user.go`

**No TableName field generated**, only pure column constant definitions:

```go
// Code generated by gencol. DO NOT EDIT.
package meta

var User = struct {
	Id string
	Username string
	Password string
	Phone string
	Email string
	IsActive string
	CreatedAt string
	UpdatedAt string
}{
	Id: "id",
	Username: "username",
	Password: "password",
	Phone: "phone",
	Email: "email",
	IsActive: "is_active",
	CreatedAt: "created_at",
	UpdatedAt: "updated_at",
}

```

## Code Optimization Contrast

### Before \(Hard\-coded Column Strings\)

Prone to spelling errors, no compile\-time detection:

```go
type UserModel struct {
	db    *gorm.DB
	model *User	
}

func NewUserModel(db *gorm.DB) *UserModel {
	return &UserModel{		
		db:    db,
		model: &User{},
	}
}

func (p *UserModel) GetByUsername(username string) (*User, error) {
	var user User
	err := p.db.Where("username = ?", username).
		Where("is_active = ?", true).
		First(&user).Error
	if err != nil {
		return nil, err
	}
	return &user, nil
}
```

### After \(Use gencol Generated Constants\)

Full IDE hints, compile\-time error checking, zero spelling errors:

```go
type UserModel struct {
	*query.BaseModel[User]
}

func NewUserModel(db *gorm.DB) *UserModel {
	return &UserModel{BaseModel: query.NewBaseModel[User](db)}
}

func (p *UserModel) GetByUsername(username string) (*User, error) {
	return p.NewQuery().
		Eq(meta.User.Username, username).
		Eq(meta.User.IsActive, true).
		First()
}
```

## Core Advantages

- **100% compatible with custom TableName**: The tool does not generate any table name logic, fully retaining your custom `TableName()` and constant table name definitions

- **Avoid magic strings**: All database column names are managed by constants, unified maintenance

- **Compile\-time safety**: Wrong column names will report errors during compilation, not online runtime errors

- **Non\-intrusive**: Does not modify any original model and business code

## Uninstall

Go has no official uninstall command, just manually remove the binary file:

```bash
# Query GOPATH bin directory path
go env GOPATH

# Uninstall (Windows)
rm $GOPATH/bin/gencol.exe

# Uninstall (Linux / Mac)
rm $GOPATH/bin/gencol

```
